# Smart Farmer Platform

A comprehensive digital platform designed to empower farmers with modern agricultural solutions, real-time insights, and sustainable farming practices.

## Features

### 🌾 Farm Digital Twin
- Real-time field visualization
- Crop growth simulation
- Irrigation prediction
- Weather impact forecasting
- Yield prediction

### 📊 IoT Integration
- Live sensor data monitoring
- Interactive sensor mapping
- Automated alerts
- Data visualization charts

### 💡 Smart Advisory
- AI-powered farming assistance
- Micro-advisory tips
- Query history tracking
- Quick advisory panel

### 🏪 Market Intelligence
- Live market prices
- Price alerts
- Community feed
- Nearby market information

### 🌱 Sustainability Tracking
- Carbon footprint monitoring
- Eco-friendly recommendations
- Green points system
- Community leaderboard
- Sustainability dashboard

## Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **UI Components**: Customized shadcn/ui
- **State Management**: React Hooks
- **Data Visualization**: Custom charting components

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/nikhil-rf/smart-farmer-platform.git
   cd smart-farmer-platform
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   ```

3. **Run the development server**
   ```bash
   pnpm dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`
